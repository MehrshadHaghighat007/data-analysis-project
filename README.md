# فاز اول پروژهٔ تحلیل داده — تشخیص فرمان گفتاری

در این پروژه، داده‌های فرمان گفتاری را برای بررسی تعمیم به گویندگان جدید تحلیل می‌کنیم. این مخزن شامل فاز اول مسیر د است. **شروع مطالعه: reports/phase1/phase1.tex یا نوت‌بوک notebooks/phase1_fa.ipynb.**

## محتوای بسته

- <code dir="ltr">src/phase1.py</code>: دریافت نسخهٔ ثابت داده، ممیزی، حذف تحلیلی نسخه‌های تکراری، تقسیم گروهی و ساخت نمودارها.
- <code dir="ltr">configs/phase1.json</code>: منبع، هش فایل، آستانه‌ها و روش تقسیم.
- <code dir="ltr">notebooks/phase1_fa.ipynb</code>: توضیحات فارسی، اجرای مرحله‌ها، جدول‌ها، شکل‌ها و امکان شنیدن نمونه‌ها.
- <code dir="ltr">tables/</code>: دادهٔ ممیزی، آمارها، خطاها و صف شنود دستی؛ سرستون‌های ماشینی انگلیسی با فرهنگ دادهٔ فارسی.
- <code dir="ltr">splits/</code>: مرجع ثابت عضویت فایل‌ها در تقسیم‌ها. برای آموزش فقط ردیف‌های <code dir="ltr">use_for_analysis=True</code> در manifest را بخوانید.
- <code dir="ltr">figures/</code>: ۱۱ تصویر حاصل از اجرای واقعی؛ شامل ۲۴ جفت موج و طیف از بخش آموزش.
- <code dir="ltr">reports/phase1/</code>: گزارش پروژه.
- <code dir="ltr">PROJECT_CARD.md</code> و <code dir="ltr">AI_USAGE.md</code>: مستندات پروژه.
- <code dir="ltr">tests/test_phase1.py</code>: آزمون‌های علمی مهم شامل نبود نشت و درستی شاخص‌های کیفیت.
